# Knights Delivery frontend

A minimal React + Vite shell for the Knights Delivery prototype. This page is presentation-only; it does not sign in users, save requests, or connect to a backend.

## Start locally

From the `frontend/` directory:

```sh
npm install
npm run dev
```

Open the local URL printed by Vite (normally `http://localhost:5173`).

Create a production build with `npm run build`.
